# تصورات مبدئية للعملاء (Demos)

كل عميل له فولدر هنا، وبيتفتح على:
`https://weblume-sa.github.io/demo/<اسم-الفولدر>/`

## عمل تصور لعميل جديد
1. انسخ فولدر `_template` لفولدر جديد باسم المحل بالإنجليزي (مثلاً `red-cap`).
2. عدّل `data.js` بس: الاسم، الألوان من اللوجو، المنيو، المواعيد، رقم الواتساب، وموقع خرايط جوجل.
3. حط اللوجو والصور في نفس الفولدر واكتب أسماءهم في `data.js`.
4. ارفع، وابعت اللينك للعميل.

`demo: true` بيظهر شريط "تصور مبدئي من Weblume" فوق. لما العميل يدفع، اعمله `false` وانقل الموقع لريبو/دومين العميل.

الصفحات دي `noindex`، يعني مش هتظهر في جوجل.
